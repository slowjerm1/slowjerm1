## About me

I’m **Enoch Baah**, a data scientist interested in applying data analysis and machine learning to practical challenges. My public projects explore predictive modeling, natural-language processing, time-series forecasting, and recommendation systems.

I value clear problem framing, thoughtful data preparation, useful evaluation, and communicating results in a way that supports better decisions.
